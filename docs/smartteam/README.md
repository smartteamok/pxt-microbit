# SmartTeam MakeCode Planning

This folder is the working technical reference for the SmartTeam MakeCode target.

Current scope:

- Base target: micro:bit-derived MakeCode target.
- Hardware: micro:bit with SmartTeam/FIFA-style educational kit.
- Course profiles: 1st through 6th grade selected at project creation time.
- Course selection is immutable for a project; changing grade means creating a new project.
- JavaScript and Python stay enabled unless later product decisions restrict them.

Documents:

- [Source Baseline](source-baseline.md): current repository state and immediate source decisions.
- [Build Notes](build-notes.md): dependency/build commands and current build observations.
- [Architecture](architecture.md): target structure and responsibilities.
- [Category Taxonomy](category-taxonomy.md): toolbox categories, owners, order, colors, and native category policy.
- [Course Filtering](course-filtering.md): proposed grade-based filtering model.
- [Block Matrix](block-matrix.md): initial block availability by grade.
- [Native Blocks Inventory](native-blocks-inventory.md): audit template for native micro:bit blocks.
- [Implementation Plan](implementation-plan.md): phased plan before coding.
- [Open Questions](open-questions.md): decisions still pending.
